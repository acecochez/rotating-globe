## Features

- **Smooth 3D Rotation**: Continuous auto-rotation
- **Country Labels**: Display country names and information
- **Interactive Controls**: Mouse drag to rotate, scroll to zoom
- **Responsive Design**: Adapts to different screen sizes

## Usage

- **Rotate Globe**: Click and drag with mouse
- **Zoom**: Scroll up/down or pinch on mobile
- **View Country**: Hover over or click on countries for labels
- **Auto-rotation**: Globe automatically rotates when not being interacted with
